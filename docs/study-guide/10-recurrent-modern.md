# 第 10 章：现代循环神经网络重点解析

[学习导览](README.md) · [本章原文](../../chapter_recurrent-modern/index.md) · [术语对照表](../GLOSSARY.zh-CN.md)

本章解决两个问题：如何改善长期信息传递，以及如何把输入序列映射为不同长度的输出序列。先修是基本 RNN、BPTT、条件概率与张量形状。学习目标不是认出门的名称，而是能沿状态路径解释信息何时保留、写入和输出，并区分训练与推断的数据来源。

## 核心关系与公式

长短期记忆网络（long short-term memory，LSTM）的关键更新为

$$C_t=F_t\odot C_{t-1}+I_t\odot\widetilde C_t,\qquad H_t=O_t\odot\tanh(C_t).$$

$C_t$ 是记忆单元状态，$H_t$ 是隐藏状态；遗忘门 $F_t$、输入门 $I_t$、输出门 $O_t$ 的值由 sigmoid 给出，位于 0 与 1 之间；$\odot$ 表示逐元素乘法。各量通常为“批量 × 隐藏维度”。当直接状态通路上的遗忘门接近 1 时，长期信息较易保留；这不是任意配置下梯度永不消失的保证。

教材的门控循环单元（gated recurrent unit，GRU）约定为

$$H_t=Z_t\odot H_{t-1}+(1-Z_t)\odot\widetilde H_t.$$

更新门 $Z_t$ 越接近 1，保留旧状态越多；重置门（reset gate）控制旧状态进入候选状态的程度。其他资料可能交换更新门的记号或采用不同的重置计算位置，读代码时以具体公式为准。

序列到序列（sequence-to-sequence，seq2seq）学习的条件概率为

$$p(y\mid x)=\prod_{t=1}^{T_y}p(y_t\mid y_{<t},x).$$

$T_y$ 是目标序列有效长度。训练时给真实前缀，推断时给已生成前缀，两者并不相同。

## 按教材顺序解析

### 10.1 长短期记忆网络 LSTM

[原文与代码](../../chapter_recurrent-modern/lstm.md)。三个门分别控制写入、遗忘和可见输出，候选记忆与旧记忆通过加法合并。区分内部记忆 $C$ 与对外隐藏状态 $H$；框架接口通常需要同时传递它们。门控结构改善可学习的长期依赖路径，但仍需要合适的初始化、学习率和训练数据。

### 10.2 门控循环单元 GRU

[原文与代码](../../chapter_recurrent-modern/gru.md)。GRU 将结构压缩为重置门、更新门与一个隐藏状态，减少状态及参数管理。重点用极限情形理解公式：更新门趋近 1 时近似复制过去，趋近 0 时采用候选状态；重置门趋近 0 时候选状态减弱对过去的依赖。“结构更简洁”不意味着在每个任务、设备上必然更准或更快。

### 10.3 深度循环神经网络

[原文与代码](../../chapter_recurrent-modern/deep-rnn.md)。堆叠 RNN 同时拥有时间方向与层方向的依赖：同一层传递上一时间状态，同一时间把下层输出交给上层。增加 `num_layers` 是增加每步的表示深度，不是增加序列长度。逐层状态的维度和初始化要一致，训练难度也可能增加。

### 10.4 双向循环神经网络

[原文与代码](../../chapter_recurrent-modern/bi-rnn.md)。双向 RNN（bidirectional RNN）分别从左右读取完整输入，再拼接两个方向的状态。若各方向隐藏维度为 $h$，输出特征通常为 $2h$。它适合允许访问完整上下文的编码或序列标注；直接用于只能看到过去的下一 token 预测，会泄漏未来信息。

### 10.5 机器翻译与数据集

[原文与代码](../../chapter_recurrent-modern/machine-translation-and-dataset.md)。英语与法语句子长度和词序不必对齐，因此不能把翻译简单看成逐位置分类。注意源语言、目标语言词表，以及 `<bos>`、`<eos>`、`<pad>` 的不同作用；截断会丢失信息，填充只是为了组成批量。有效长度（valid length）必须与截断后的 token、结束符处理一致。

### 10.6 编码器—解码器架构

[原文与代码](../../chapter_recurrent-modern/encoder-decoder.md)。编码器（encoder）把源序列转成供解码器使用的状态，解码器（decoder）逐步产生目标分布。本节的接口抽象比具体 RNN 更通用：后续注意力模型会把整段编码表示也纳入状态，不必始终压缩为单个向量。读 `init_state` 和 `forward` 的约定，比只读架构图更能理解二者如何交接。

### 10.7 用 Seq2Seq 进行机器翻译

[原文与代码](../../chapter_recurrent-modern/seq2seq.md)。教师强制（teacher forcing）用真实目标前缀训练，预测时则反馈模型输出。损失掩码（loss mask）排除填充位置；本版 `Seq2Seq.loss` 将有效位置损失求和，再除以有效 token 数，因此长句通常贡献更多有效项。若改为逐句平均，样本权重就会改变。BLEU 使用 $n$ 元片段匹配与长度惩罚，教材的简化实现适合解释机制，不应不注明细节就与外部语料级 BLEU 排名比较。

### 10.8 束搜索

[原文](../../chapter_recurrent-modern/beam-search.md)。贪心搜索（greedy search）只保留当前最佳扩展，可能错过更高联合概率的完整序列。束搜索（beam search）保留有限条候选前缀，以更多计算换取更广搜索；束宽为 1 时接近贪心搜索。候选的终止规则和长度归一化决定评分偏好，更大束宽不保证更高翻译质量，也不保证找到全局最优。

## 易错点与自测

- **LSTM 忘记旧记忆后能靠输出门恢复吗？** 不能；输出门只控制当前记忆如何显露，不重新创造被丢弃的信息。
- **双向编码器是否与自回归解码器冲突？** 不冲突，完整源句已知；限制的是不能读取未来目标 token。
- **补零是否等同于正确处理填充？** 不等同。嵌入、递推、注意力和损失分别怎样处理 padding，需要逐处核对。
- **训练损失低但生成差，首先查什么？** 目标右移、训练/推断前缀差异、结束符、有效长度，以及解码评分规则。
- **束宽增大为何不一定提升 BLEU？** 搜索优化的是模型评分；该评分与评价指标及人类偏好并不完全一致。

## 小实验建议（本次未执行）

1. 在同一小语料和相近参数预算下比较基本 RNN、GRU、LSTM；记录参数量、每轮耗时、验证困惑度与长距离依赖测试。隐藏维度相同不代表参数预算相同，需在报告中明确比较口径。
2. 对同一个训练好的翻译模型比较贪心解码与若干束宽，固定长度惩罚与最大长度。记录输出长度、模型对数概率和同一实现的 BLEU；少量演示句只能作为案例，不能据此断言总体质量提升。
